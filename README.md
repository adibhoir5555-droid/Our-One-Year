## GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Note: a public GitHub Pages site is not truly private. Anyone with the URL can potentially access it. The `noindex` tag discourages search-engine indexing, but it is not access control.
